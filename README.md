# EShop - розподілений застосунок на базі .NET Aspire

Хмарно-орієнтований інтернет-магазин, створений з використанням **.NET 10** та **Aspire 13**, що має бекенд на основі Minimal API та фронтенд на Blazor Server. Підтримує повний набір операцій CRUD для **Products**, **Shopping Cart** та **Orders**.
